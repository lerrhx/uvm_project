# Ассемблер и интерпретатор УВМ (Вариант 31)

## Описание
Программа переводит текст на учебном ассемблере в машинный код и выполняет его.

## Как запустить
1. Собрать код:
   `python assembler.py`
2. Выполнить код:
   `python interpreter.py`

## Этапы
- Этап 1-2: `assembler.py` (трансляция в байты).
- Этап 3-5: `interpreter.py` (выполнение и АЛУ).
